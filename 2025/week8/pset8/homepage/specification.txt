# HTML elements
1. heading tags (<h3>): Will use to add heading to web page.
2. anchor tags (<a href="">): use to add external or internal links. (can be linked to other pages or other webpages on internet)
3. div tags (<div>): it basically use to divide and organize web elements and can be use as a wrapper holding other html elements. This is a block element.
4. lists (ordered & unordered ): List on web pages. <ul> is used for unordered list. <ol> is used for ordered list.
5. tables <table>: use to add table in web pages. I used it to show my contact info.
6. img tags (<img>): used to add image on web pages. it basically accept a `src` to make the image visible.
7. paragraph tag (<p>): basic paragraph tag in html.
8. link (<links href="../bootstrap.min.css" rel="stylesheet>): use to link external stylesheets and fonts. usually placed in the <head> of the html
9. bold <b>: use to bold out the text.
10. span tag <span>: span tag is an inline html element used to apply classes to smaller chunks of text.
11. ifranes: used to emmbed external websites on within the webpage. I used it to emmbed a video from youtube.
12. em tag (<em>): to emphasize text. used in guestbook cards.
